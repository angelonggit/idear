六张成绩单 REPORT CARDS

大家共用的骨架 CORE LOOP

盖教室/设施→招老师→招学生（带学费）→ 满足需求：吃、厕所、卫生、娱乐、压力→学年末考试 / 毕业→声望 + 钱→ 扩建，再来一年 ↺

这一套基本是主题医院把“病人”换成“学生”、把“治愈”换成“及格”。六款游戏都没脱离它，差别在往骨架上贴什么肉。

它们站在哪 POSITIONING

位置是我读完评测后的主观判断，用来讨论，不是测量。左上角那块目前没有人认真做过。

集体丢分的地方 COMMON FAULTS

开局重复，后期发空双点校园被骂“每关复制粘贴房间然后快进到学年末”；Academia 也被说后期重复。
“上课”本身最抽象教学通常就是一个房间加一个进度条。口袋学院的评测直说：很少看到老师真的在讲课。
学生只是满意度条双点给了交友和恋爱，但学生很少真的“长大”，毕业后也没有回响。
故事普遍很薄Academia 的评测几乎都提到这点，大家默认经营游戏不需要故事。
外部压力只有一两个数家长、升学率、教育局、隔壁学校抢生源，多数只是一个声望值。学园构想家的“填鸭还是素质”是少见的例外。
界面难找学园构想家被吐槽 UI 区分度差，玩到中期还找不到想开的管理面板。经营游戏的老病。
